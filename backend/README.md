# Glean Backend

글린의 작품과 회차 데이터를 관리하는 REST API 서버입니다.

## Tech Stack

- NestJS
- Prisma
- MySQL
- TypeScript

## Role

- Work / Episode REST API
- Prisma를 통한 MySQL 연동
- 작품과 회차의 CRUD 처리

## Development

```bash
npm install
npx prisma generate
npm run start:dev
```

전체 프로젝트 설명은 [루트 README](../README.md)를 참고하세요.
