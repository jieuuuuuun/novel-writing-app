# Glean Frontend

글린의 작품·회차 관리 UI와 글쓰기 워크스페이스를 제공하는 Frontend입니다.

## Tech Stack

- Next.js
- React
- TypeScript
- App Router
- CSS Modules

## Role

- 작품 및 회차 관리 UI
- 작품별 워크스페이스와 회차 에디터
- Desktop / Mobile 반응형 화면
- NestJS REST API 연동

## Development

```bash
npm install
npm run dev
```

전체 프로젝트 설명은 [루트 README](../README.md)를 참고하세요.
